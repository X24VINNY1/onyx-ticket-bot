🚀 Interactions Endpoint URL

Copy your Vercel deployment URL and paste it into the Interactions Endpoint URL field in the Discord Developer Portal:

https://<your-deployment-domain>.vercel.app/api/interactions

⚙️ Vercel Environment Variables

Add these variables in your Vercel Project Settings (Settings → Environment Variables):

Variable Required Description
DISCORD_TOKEN Yes Your Discord Bot Token
DISCORD_PUBLIC_KEY Yes Ed25519 Public Key from General Information tab
DISCORD_APP_ID Yes Application ID
STAFF_ROLE_ID No Role ID allowed to view/claim all ticket channels
DISCORD_GUILD_ID No Optional: Guild ID for instant slash command sync

📋 Quick Setup Steps

1

Set Interactions Endpoint URL

Go to Discord Developer Portal → Applications → General Information → Interactions Endpoint URL. Paste your Vercel URL ending in /api/interactions.

2

Register Slash Commands

Run npm run register locally or via GitHub Actions with your env variables to sync /setup-tickets and /channel.

3

Deploy Ticket Panel

In your Discord server, type /setup-tickets to post the interactive dropdown station.
